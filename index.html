The recipe

Four steps, using ordinary clock arithmetic.

Choose a prime \(p\). “Modulo \(p\)” below means that numbers wrap back to zero after \(p-1\), just as hours wrap around a clock. The prime condition is what makes every crossing unique.

Why prime?

We must be able to undo every nonzero multiplication.

This is not about ordinary lines crossing at integer coordinates. Our grid positions are labels \(0,\ldots,p-1\), and every result is wrapped back into that set.

Two cards with different steps meet where

\[(m_1-m_2)x\equiv b_2-b_1\pmod p.\]

Finding \(x\) means undoing multiplication by \(m_1-m_2\). When \(p\) is prime, every nonzero value has exactly one undo, so the equation has exactly one answer.

With \(p=6\), this breaks: \(2x\equiv0\pmod6\) has two answers, \(x=0\) and \(x=3\). The cards \(y=0\) and \(y=2x\) would therefore share two grid symbols.

The Fermat connection. Fermat’s little theorem says \(a^{p-1}\equiv1\pmod p\) for nonzero \(a\). Therefore \(a^{p-2}\) undoes multiplication by \(a\). It proves exactly the property we need, although the simpler “no shared factor with a prime” argument is enough here.[3]

Create the grid symbols

Make one symbol for each position in a \(p\times p\) grid.

\[G(x,y),\qquad 0\le x,y<p\]

Add direction symbols

Add one symbol for each wrapped slope, plus a vertical direction.

\[D(0),\ldots,D(p-1),D(V)\]

Build the sloping cards

For every choice of \(m\) and \(b\), take one point in every grid column and add its direction.

\[C(m,b)=\{G(x,(mx+b)\bmod p)\mid x=0,\ldots,p-1\}\cup\{D(m)\},\quad 0\le m,b<p\]

Close the pattern

Add \(p\) vertical cards. Finish with one card containing all direction symbols.

\[V(a)=\{G(a,y)\mid y=0,\ldots,p-1\}\cup\{D(V)\},\quad 0\le a<p\]
\[H=\{D(0),\ldots,D(p-1),D(V)\}\]
Why it works

There are only five cases.

Same direction

Two cards with the same \(m\) never meet on the grid. They share exactly their direction symbol \(D(m)\).

Different directions

A crossing must satisfy \((m_1-m_2)x=b_2-b_1\). Because \(p\) is prime, as \(x\) runs through the wrapped values, the left side takes every value exactly once. So there is exactly one crossing.

Sloping and vertical

The vertical card fixes \(x=a\). This forces one shared grid symbol: \(G(a,ma+b\bmod p)\).

Two vertical cards

Their grid columns are separate, but both carry \(D(V)\). That is their one match.

The final direction card

It contains no grid symbols. It meets every previous card at exactly that card’s direction symbol.

The ceiling

If no symbol appears everywhere, then \(N\le s^2-s+1\).

\[\boxed{N\le s^2-s+1}\]

Exclude the boring case where one symbol appears on every card. Then any symbol can occur on at most \(s\) cards: a card without that symbol has only \(s\) different ways to meet those cards.

Now choose one card. Each of its \(s\) symbols can connect it to at most \(s-1\) other cards. Therefore \(N-1\le s(s-1)\). The prime-\(p\) construction reaches this bound exactly.

from itertools import combinations


def is_prime(p: int) -> bool:
    if p < 2:
        return False
    divisor = 2
    while divisor * divisor <= p:
        if p % divisor == 0:
            return False
        divisor += 1
    return True


def dobble(p: int) -> list[frozenset[str]]:
    if not is_prime(p):
        raise ValueError("This simple recipe requires a prime p")

    cards: list[frozenset[str]] = []

    # Wrapped lines.
    for m in range(p):
        for b in range(p):
            card = {f"G({x},{(m*x+b) % p})" for x in range(p)}
            card.add(f"D({m})")
            cards.append(frozenset(card))

    # Vertical cards.
    for a in range(p):
        card = {f"G({a},{y})" for y in range(p)}
        card.add("D(vertical)")
        cards.append(frozenset(card))

    directions = {f"D({m})" for m in range(p)}
    directions.add("D(vertical)")
    cards.append(frozenset(directions))

    expected = p*p + p + 1
    symbols: set[str] = set()
    for card in cards:
        symbols.update(card)

    assert len(cards) == len(symbols) == expected
    assert all(len(card) == p + 1 for card in cards)
    assert all(len(a & b) == 1 for a, b in combinations(cards, 2))
    assert all(sum(s in c for c in cards) == p + 1 for s in symbols)
    return cards


deck = dobble(7)  # 57 cards, 8 symbols each
A surprising limit

The count pattern does not guarantee the next deck exists.

6Impossible: no complete 43-card pattern.[2]
10Impossible: no complete 111-card pattern.[2]
12Open: nobody knows whether the 157-card pattern exists.[2]

The plain wrapped-grid recipe works when \(p\) is prime. A more elaborate version also works when \(p\) is a power of one prime—for example \(4=2^2\), \(8=2^3\), or \(9=3^2\).

But not every value works. The count grows by \(2s\), but that arithmetic does not construct the next deck.

The smallest unresolved case is \(p=12\): 13 symbols per card and 157 cards. This is a genuine open problem, not merely a missing construction.
