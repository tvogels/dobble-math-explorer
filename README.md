# Dobble, constructed

An interactive, plain-language explanation of the mathematics behind Dobble/Spot It.

The page includes:

- a D3 card-pair and wrapped-grid explorer;
- KaTeX-rendered formulas;
- a constructive algorithm and proof;
- deck-size bounds and known existence limits;
- a verified Python generator.

Open the published page through GitHub Pages. The site itself uses pinned CDN releases of D3 and KaTeX.
